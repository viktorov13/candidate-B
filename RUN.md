# Как запустить

Нужен Python 3.9 или новее. Сторонние пакеты не нужны.

```
python report.py --date 2026-11-10
python report.py --date 10.11.2026 --csv report.csv   # то же, плюс CSV для Excel
python report.py --date 2026-11-10 --data path/to/data # другая папка с CSV
python -m unittest test_report -v                       # проверки расчёта
```

По умолчанию данные берутся из папки `data/` рядом со скриптом. Если в данных есть ошибка, программа завершается с кодом 1 и указывает файл и строку.

Файлы:
- `report.py` - программа;
- `test_report.py` - тесты: контрольная дата 10.11.2026, возврат, переплата, отмена;
- `DECISIONS.md` - принятые решения и допущения;
- `NOTE.md` - записка бухгалтеру;
- `report-2026-11-10.csv` - готовый отчёт на контрольную дату.
